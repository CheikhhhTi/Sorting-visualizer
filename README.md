# Sorting Algorithm Visualizer

A React-based web application that provides visual demonstrations of various sorting algorithms in action.

## Features

- Real-time visualization of sorting algorithms
- Multiple sorting algorithms implemented:
  - Bubble Sort
  - Insertion Sort
  - Quick Sort
  - Heap Sort
- Adjustable array size
- Animation controls (start, stop)
- Color-coded visualization:
  - Purple: Unsorted elements
  - Red: Elements being compared
  - Yellow: Elements being swapped
  - Green: Sorted elements

## Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm (v6 or higher)

### Installation
1. Clone the repository
```bash
git clone https://github.com/yourusername/sorting-visualizer.git
```

2. Navigate to project directory
```bash
cd sorting-visualizer
```

3. Install dependencies
```bash
npm install
```

4. Start the development server
```bash
npm start
```

## Usage

1. Click "Generate New Array" to create a new random array
2. Select any sorting algorithm to start the visualization
3. Use the "Stop" button to interrupt the current sorting process
4. Watch the visual representation of the sorting algorithm in action
